# Hola, soy David Rodríguez Rives 👋
 
**Desarrollador Full Stack y artista 2D/3D de personajes para videojuegos**, con foco en realidad aumentada y experiencias interactivas en web.
 
📍 Fuenlabrada, Madrid, España · 🗣️ Español (nativo) · Inglés (C1)
🔎 Abierto a nuevas oportunidades · 🌐 [Portfolio](https://miniesda.github.io/my-own-web-page/)
 
## Sobre mí
 
Combino desarrollo de software y arte 3D: puedo construir la aplicación y también crear los personajes y escenas que la hacen atractiva. Me interesan especialmente la realidad aumentada, la informática gráfica y los videojuegos.
 
## Experiencia
 
- **Universidad de Alicante** · Docencia e investigación (2025 - 2026)
- **JdeRobot-Unibotics** · Full Stack Developer (2023 - 2024). Migración de los componentes React de RoboticsAcademy de JavaScript a TypeScript con un nuevo frontend, y contribuciones en RoboticsInfrastructure (texturas y branding).
