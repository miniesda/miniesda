# Hi, I'm David Rodríguez Rives 👋
 
**Full Stack Developer and 2D/3D Character Artist for video games**, focused on augmented reality and interactive web experiences.
 
📍 Fuenlabrada, Madrid, Spain · 🗣️ Spanish (native) · English (C1)
🔎 Open to new opportunities · 🌐 [Portfolio](https://miniesda.github.io/my-own-web-page/)
 
## About me
 
I combine software development with 3D art: I can build the application and also create the characters and scenes that bring it to life. I'm especially interested in augmented reality, computer graphics and video games.
 
## Experience
 
- **University of Alicante** · Teaching and research (2025 - 2026)
- **JdeRobot-Unibotics** · Full Stack Developer (2023 - 2024). Migrated RoboticsAcademy's React components from JavaScript to TypeScript with a new frontend, and contributed to RoboticsInfrastructure (textures and branding).

## Featured projects
 
- 📱 **Master's thesis:** augmented reality web app for the Seville, Mallorca and Bilbao metro systems [Link](https://miniesda.github.io/VisualMetros3D/)
- 📄 **Bachelor's thesis:** published at *Robotics in Education (RiE) 2025* [Link](https://link.springer.com/chapter/10.1007/978-3-031-98762-5_33)
- 🏎️ **Street Race:** racing game built with A-Frame and Javascript, featuring a GLB city [Link](https://miniesda.github.io/my-own-web-page/FastAndFurious)
